# Plan 03-01: Inventory & Stock Adjustments

## Objective
Implement the near-expiry report and the manual stock adjustment flow with mandatory audit trails.

## Tasks

### 1. BatchRepository Enhancements
- Add `findNearExpiry(branchId, days)` to query batches expiring within the window.
- Add `updateQuantityManual(batchId, adjustment, reason, userId)` to handle damage/loss.

### 2. InventoryService Implementation
- `getNearExpiryReport(branchId, days)`: Returns formatted report.
- `adjustStock(dto, userId)`: Wraps repository update + `stock_movements` log in a transaction.

### 3. InventoryController Routes
- `GET /inventory/near-expiry`: Query near-expiry batches.
- `POST /inventory/adjust`: Submit a stock adjustment.

## Success Criteria
- `GET /inventory/near-expiry?days=30` returns correct batches.
- `POST /inventory/adjust` updates `inventory_batches.quantity` and creates a `stock_movements` record with type `adjustment`.
